潜在国民收入与缺口

发表于2026-09-28|更新于2026-09-28|经济学笔记
|浏览量:

潜在国民收入

潜在GDP或充分就业产出，是指一个国家在一定时期内，在现有技术、资源和制度条件下，所有生产要素（如劳动、资本、土地）得到充分利用时所能持续创造的最大国民收入水平。它反映了经济体的长期供给能力，而非短期的实际需求波动。实际国民收入围绕潜在国民收入上下波动，两者之间的差距即为产出缺口，用于判断经济处于过热还是衰退状态。

GDP缺口／产出缺口

衡量实际产出和潜在产出的距离(差值)：

GDP缺口 = 实际GDP − 潜在GDP
产出缺口% = (实际GDP − 潜在GDP) ÷ 潜在GDP

潜在GDP＝劳动力、资本、技术充分利用、且不持续推高物价时经济能稳稳产出的水平（不是物理上限，含自然失业率）。

正负含义：

正缺口：实际＞潜在，需求偏强、资源偏紧，常被叫“过热/通胀性产出缺口”。会推高工资和物价，央行倾向加息、财政倾向减支增税。
负缺口：实际＜潜在，有失业、闲设备、需求不足，叫“衰退/通缩性产出缺口”。物价上涨慢甚至跌，央行倾向降息、财政倾向加支减税。

通缩，通胀缺口

通货紧缩缺口（deflationary gap）：均衡总支出＜充分就业所需总支出，即总需求不足导致实际收入低于潜在收入。补上这个缺口所需增加的总支出量，就是通缩缺口。政策：扩需求（增G、减税、降息）。

通货膨胀缺口（inflationary gap）：实际总支出＞充分就业收入对应总支出，资源已充分就业，再多需求只抬物价不增产。要消除需减少的总支出量，就是通胀缺口。政策：压需求（减G、增税、加息）。

货币政策、泰勒规则里也把 inflation gap 定义为：

通胀缺口 = 实际通胀率 − 通胀目标

正：通胀超目标→偏紧（加息）
负：通胀低于目标→偏松（降息）

它和GDP缺口不是一回事：一个看“产量冷热”，一个看“物价偏离目标”。泰勒规则常同时用两者：

政策利率≈通胀+中性实际利率+0.5×通胀缺口+0.5×产出缺口。

GDP缺口与通胀缺口对照表
实际GDP＜潜在 → 负GDP缺口 → 常伴通缩缺口/通缩压力 → 扩张财政货币
实际GDP≈潜在 → 缺口≈0 → 支出接近充分就业支出 → 物价稳定
实际GDP＞潜在 → 正GDP缺口 → 常伴通胀缺口/通胀压力 → 紧缩财政货币
实际通胀＞目标 → 正通胀缺口 → 即便单独看也要控物价（但若同时负产出缺口，政策会纠结）
